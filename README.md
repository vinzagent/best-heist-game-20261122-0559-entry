The Gilded Vault — a complete original top-down heist game: sneak through Meridian Bank at midnight, dodge 4 patrolling guards with vision cones and suspicion, slip past 4 sweeping security cameras, time 2 pulsing laser grids, hack the terminal to kill the cameras, lift $8,000 of loot including the Meridian Star, and escape to the getaway van before the 4-minute clock runs out or the alarm hits lockdown. 6 loot targets with dollar values, a live alarm meter with 3 escalation levels, coin distractions, click-to-walk and keyboard play, synthesized WebAudio sound, and 4 staged screenshot scenes.

## Run it

Serve `game/` with any static server and open `index.html`, e.g.:

```sh
cd game && python3 -m http.server 8123
```

Then open http://localhost:8123/ in a desktop browser. No build step, no network requests — plain static files under game/.
